# Локальная версия и проверки — 23 октября 2026

## Изменения интерфейса

- Помощник открывается компактным чатом поверх кабинета и разворачивается в полный экран с общей историей. Верхняя навигация открывает полный раздел.
- Enter отправляет сообщение, Shift+Enter добавляет строку. Поле очищается сразу; после ошибки вопрос возвращается отдельной кнопкой.
- Удалены розовый персонаж и дублирующая плашка помощника. Увеличена плавающая кнопка, используется иконка диалога и спокойное состояние ожидания.
- В кабинете есть два явно обозначенных макета: банковский баннер после основного блока и партнёрский после материалов. Кнопки открывают пояснение, без подключения услуг и передачи данных.
- Dev proxy по умолчанию использует локальный backend 127.0.0.1:8010, а не общий VPS. Для другого адреса задайте DELO_API_TARGET.

## Настоящая локальная модель

На Mac Apple Silicon проверена **Qwen3-4B-Instruct-2507 Q4_K_M**, llama.cpp b11669 с Metal. Это отдельная локальная конфигурация, а не модель 27B из серверного примера. Старые ключи и платные inference API не используются.

- Исходная модель: https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507 — Apache 2.0.
- GGUF: https://huggingface.co/unsloth/Qwen3-4B-Instruct-2507-GGUF, ревизия a06e946bb6b655725eafa393f4a9745d460374c9.
- Файл: Qwen3-4B-Instruct-2507-Q4_K_M.gguf, 2497281120 байт.
- SHA256: 3605803b982cb64aead44f6c1b2ae36e3acdb41d8e46c8a94c6533bc4c67e597.
- Runtime: https://github.com/ggml-org/llama.cpp/releases/tag/b11669.

Веса и двоичные runtime не включены в Git. Требуется загрузка и отдельная настройка inference по docs/ASSISTANT_BACKEND.md. Пример локальных параметров backend:

```dotenv
ASSISTANT_ENABLED=true
ASSISTANT_MODEL=Qwen3-4B-Instruct-2507-Q4_K_M
ASSISTANT_BASE_URL=http://127.0.0.1:8081/v1
ASSISTANT_TIMEOUT_SECONDS=120
ASSISTANT_TURN_TIMEOUT_SECONDS=240
ASSISTANT_MAX_OUTPUT_TOKENS=1024
ASSISTANT_HISTORY_TURNS=4
ASSISTANT_MAX_TOOL_ROUNDS=2
DEMO_TOOLS_ENABLED=false
```

Создайте отдельный новый токен для ASSISTANT_API_KEY и передайте тот же токен llama-server через `--api-key-file`. Не используйте общий/пустой секрет для публичного inference. Проверенные параметры llama-server: `--alias Qwen3-4B-Instruct-2507-Q4_K_M --host 127.0.0.1 --port 8081 --ctx-size 16384 --parallel 1 --gpu-layers 99 --threads 6 --cache-type-k q8_0 --cache-type-v q8_0 --jinja --reasoning off --no-ui`. Также требуется путь к модели через `-m`.

Локальные порты: web 5176, API 8010, inference 8081. В dev frontend используйте `npm run dev -- --port 5176`; backend — `python -m uvicorn app.main:app --host 127.0.0.1 --port 8010` из backend с настроенными .env и зависимостями. Cookie Secure для localhost HTTP отключается только в локальной конфигурации. Секреты, база, история, архивы VPS и абсолютные пути компьютера не включены в поставку.

## Известные ограничения

Расширенная оценка модели: из 12 кейсов 11 дали HTTP 200, один длинный бизнес-план завершился ошибкой лимита ответа. HTTP 200 не означает смысловую корректность: встречались выдуманные обозначения источников, ошибочное словесное утверждение о смене роли и неточные объяснения границ демонстрации. Серверные права от текста модели не меняются; инструменты только читают данные. Общая арифметика бизнеса пока не вынесена в детерминированные калькуляторы, LaTeX-рендер отсутствует.

Нужны: регрессии качества ИИ, обработка длинных ответов, валидация источников, лимиты входа, readiness PostgreSQL, проверка и обновление зависимостей, публичный TLS/secure-cookie. На прежнем VPS при аудите включён DEMO_TOOLS_ENABLED; перед публичным обновлением выключить. VPS с 889 MiB RAM не подходит для этой 4B-модели вместе со всем приложением. Удаление дисковых файлов не решает нехватку RAM.

Единый Docker Compose основного приложения по умолчанию запускается с отключённой моделью. Успешный локальный прогон на Mac не подтверждает автономный Docker-запуск всего комплекта с моделью на чистом ПК. Подписание и выдача средств исключены из MVP.

Экспертная оценка аудита: MVP 76/100, backend 86/100, UX 80/100, ИИ 63/100. Это не официальные баллы жюри и не процент покрытия. VPS в рамках этой публикации не обновляется.
